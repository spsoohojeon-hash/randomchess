# 랜덤능력체스 — GitHub용 전체 소스

26종 능력, 로컬 2인, 방 코드 온라인 대전, 재접속, 재대국, 기보와 로컬 자동 저장을 포함합니다.
ChatGPT 계정이나 Sites 프로젝트 설정 없이 실행하도록 정리한 소스입니다.

**코드는 GitHub 저장소에서 관리하고, 온라인 게임은 Cloudflare Workers + D1에 배포합니다.**
이 소스를 GitHub Pages에 올리는 것만으로 게임이 실행되지는 않습니다.
이 프로젝트는 서버 렌더링과 `/api/rooms` 서버 API를 사용합니다.
[GitHub Pages는 정적 파일 호스팅 서비스입니다.](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

## 1. GitHub에 올리기

기존 저장소의 소스 파일을 직접 수정하고 커밋하면 됩니다. 업데이트 ZIP을 다시 업로드하거나 압축을 풀 필요가 없습니다.
최상위에서 `package.json`, `README.md`, `wrangler.jsonc`, `app`, `lib`를 관리합니다.

기존 랜능체 저장소를 사용한다면 새 브랜치에서 변경사항을 확인한 뒤 반영하세요.
GitHub Desktop을 쓴다면 저장소를 로컬에 복제하고 파일을 복사한 다음 Commit → Push 하면 됩니다.
설치 후 생기는 `node_modules`, `dist`, 로컬 DB는 업로드 대상이 아닙니다.

## 2. 내 컴퓨터에서 실행

**Node.js 24 이상, pnpm 11.19.0**을 사용합니다.
필요한 pnpm 버전은 `package.json`에도 지정되어 있습니다.

```bash
npm install --global pnpm@11.19.0
pnpm install --frozen-lockfile
pnpm db:migrate:local
pnpm dev
```

터미널에 표시되는 주소(기본 `http://localhost:5173`)에 접속합니다.
로컬 실행에는 Cloudflare 로그인이나 실제 D1 계정이 필요하지 않습니다.
DB와 방 정보는 컴퓨터의 `.wrangler/state`에 저장됩니다.

온라인 참가를 로컬에서 확인하려면 서로 다른 브라우저 프로필을 사용하세요.
첫 창에서 방을 만들고, 다른 창에서 방 코드를 입력해 참가합니다.

## 3. 인터넷에 배포하기

Cloudflare 계정에 로그인한 뒤 이 게임 전용 D1 데이터베이스를 만듭니다.

```bash
pnpm exec wrangler login
pnpm exec wrangler d1 create randomchess-db
```

출력된 `database_id`로 **`wrangler.jsonc`에 있는 임시 ID**를 교체합니다.
바인딩 이름 `DB`와 `migrations_dir`는 유지합니다.
여러 Cloudflare 계정을 사용한다면 `wrangler.jsonc`에 해당 `account_id`도 지정합니다.
`name`은 사용할 Worker 이름이며, 이미 운영 중인 다른 Worker와 구분해서 정합니다.

그다음 데이터베이스 테이블을 만들고 게임을 배포합니다.

```bash
pnpm db:migrate:remote
pnpm build
pnpm run deploy
```

성공하면 터미널에 게임 주소가 표시됩니다. 친구에게 그 주소와 방 코드를 보내면 됩니다.
클라이언트 화면과 서버 API는 같은 주소에서 제공해야 합니다.

설정을 바꾼 뒤에는 `pnpm build`를 다시 실행해야 배포 결과에 반영됩니다.
이미 적용한 SQL 파일을 수정하지 말고, DB 구조가 바뀌면 `pnpm db:generate`로 새 마이그레이션을 만듭니다.

참고: [D1 시작 안내](https://developers.cloudflare.com/d1/get-started/),
[D1 마이그레이션](https://developers.cloudflare.com/d1/reference/migrations/),
[Vinext의 Cloudflare 배포 안내](https://github.com/cloudflare/vinext#cloudflare-workers).

## 4. GitHub와 자동 배포 연결

위의 첫 배포가 완료되면 Cloudflare Workers의 Git 연결 기능으로 GitHub 저장소를 연결할 수 있습니다.
같은 Worker와 저장소를 선택하고 다음 명령을 지정합니다.

| 설정 | 값 |
| --- | --- |
| 프로젝트 루트 | `package.json`이 있는 폴더 |
| Node.js | `24` |
| 빌드 명령 | `pnpm install --frozen-lockfile && pnpm build` |
| 배포 명령 | `pnpm run deploy` |

DB 구조를 변경할 때만 필요한 마이그레이션을 별도로 적용합니다. 능력 상태는 기존 게임 JSON에 저장하므로 이번 능력 추가에는 DB 마이그레이션이 필요하지 않습니다.
DB 마이그레이션을 실행하는 배포 토큰에는 해당 계정의 D1 편집 권한도 필요합니다.
로그인 토큰은 저장소에 넣지 말고 배포 서비스의 비밀 환경변수로 관리합니다.
[Cloudflare 빌드 설정](https://developers.cloudflare.com/workers/ci-cd/builds/configuration/)

## 게임 규칙과 데이터

체크와 체크메이트를 사용하지 않으며 **킹 포획**으로 승리합니다. 킹은 공격받는 칸으로 움직일 수 있고, 공격받는 칸을 지나 캐슬링할 수도 있습니다.
전체능력묶음 또는 선택능력묶음을 고를 수 있습니다. 선택능력묶음은 체크한 능력 안에서만 무작위 배정합니다. 한 개만 선택하면 양쪽에 같은 능력을 배정하고, 둘 이상이면 서로 다른 능력을 배정합니다. 로컬은 현재 차례의 능력을 확인하고 상대의 미발동 능력은 ?로 표시합니다. 온라인에서는 자신의 능력만 확인할 수 있습니다. 5수 앞과 양심테스트는 대국 화면에서 이름과 설명을 공개하지 않습니다. 로컬에서 백·흑 능력을 각각 지정하거나 한쪽만 지정할 수 있으며 같은 설정으로 재대국할 수 있습니다.
선택 목록은 브라우저에 저장됩니다. 온라인 방은 생성 시 선택한 목록을 보관하고 재접속·재대국에도 그대로 사용합니다. 기존 방의 풀도 유지하며 DB 변경은 필요하지 않습니다.
능력 도감은 이름과 능력 설명만 표시합니다. 특수승패 조건은 도감에서 숨기되 실제 게임 판정은 유지합니다.

능력: 네크로맨서, 존나 야생마, 우주여행, 더블무브, 평등국가, 반동분자, 퇴마(물리), 왕의 귀환.
기존 확장 9종: 폭탄 발사대, 그 수 하지 마, 테무산 타임스톤, 극한의 효율, 속전속결, 이 국가는 여왕이 통치한다, 다재다능, 5수 앞, 양심테스트.

새 확장 9종: 버로우, 나는 내가 빛나는 나이트인 줄 알았어요, 전진밖에 모르는 병신들, 진-짜 사기적인 능력, 전군 앞으로!, 오성장군, 개틀링건, You Shall Not Pass, 백마 탄 왕자님·흑마 탄 임금님.

- 버로우: 킹 외 내 기물을 보드에서 숨깁니다. 이동·피격 불가, 해당 칸이 비어 있을 때만 복귀하며 양쪽 행동 모두 무료입니다. 상대에게 숨은 위치와 기물 데이터를 보내지 않습니다.
- 점프: 버튼으로 발동, 3회. 기물 종류와 관계없이 직선·대각선으로 적을 뛰어넘어 빈칸에 착지합니다. 아군은 넘지 못하고 이동에 한 턴을 씁니다.
- 전진 폰과 무능력: 무료 발동. 전진 폰은 정면 한 칸 포획으로 영구 변경, 무능력은 보드 위 내 기물에 무지개 테두리만 적용합니다.
- 전군 앞으로: 첫 사용 무료. 막힌 폰은 그대로 두고 동시에 한 칸씩 이동합니다. 끝줄은 퀸 승격. 재사용은 기존 내 룩 두 개를 골라 희생하며 한 턴을 씁니다.
- 오성장군: 첫 포획부터 합산합니다. 기존 나이트·비숍을 무료로 지정합니다. 장군 이동 후 휘하 중 한 기물만 추가 이동하며, 추가 이동은 건너뛸 수 있습니다. 장군 또는 휘하가 잡혀도 새 기물을 생성하지 않습니다. 4회부터 장군과 휘하 위치 교환은 한 턴이며 추가 이동을 발생시키지 않습니다.
- 개틀링건: 퀸의 폰 포획만 충전합니다. 최대 8발이며 왼쪽 탄약 표시는 소유자에게만 보입니다. 일반 사격 1발, 8방향 범위 사격 8발. 범위 사격의 각 명중 지점마다 3×3 적 기물을 제거합니다. 모든 광선은 발사 전 판 기준으로 계산해 관통하지 않습니다. 사격은 아군에 막히고 아군을 제거하지 않습니다. 팀킬은 퀸의 아군 폰 직접 포획만 가능합니다.
- You Shall Not Pass: 비숍의 세로줄 전체 적 기물 제거, 킹 면역. 버튼 발동, 1회, 한 턴.
- 융합: 나이트가 룩(백) 또는 킹(흑)의 칸으로 합쳐지며 무료·영구 적용됩니다. 흑의 연속 이동은 같은 융합 기물로 나이트 이동 후 킹 이동, 총 2회입니다. 흑마가 혼자 남은 상태에서 상대 행동 후 받는 체크를 누적해 5회면 흑 패배입니다. 일반 체크에 따른 이동 금지는 없습니다.
- 5수 앞·양심테스트: 발동 선택창의 제목·설명을 동일하게 표시하고 능력명·효과를 노출하지 않습니다. 결과 문구도 중립적으로 표시합니다.

원본 `randomchess_v71_fix.zip` 및 이전 전체 소스의 카드 정의를 바탕으로 재구현했습니다.
야생마는 3×2 또는 2×3 점프이고, 반동분자는 킹이 잡힌 뒤 조건부로 발동합니다.
왕의 귀환의 지속 횟수는 킹 이동 시 줄어듭니다.
더블무브와 우주여행은 ‘이 국가는 여왕이 통치한다’의 퀸 및 왕룩도 직접 포획할 수 없습니다.
되감기로 되감기 사용 횟수를 복구할 수 없습니다.
폭탄은 일반 이동 또는 우주여행의 첫 포획에서 발동하며, 퇴마의 범위 제거는 포획 전투로 계산하지 않습니다.

온라인 상태는 서버가 판정하고 D1에 저장하며 약 1.2초 간격으로 동기화합니다.
방은 생성 7일 후 만료됩니다. 만료된 DB 행을 자동 삭제하는 작업은 포함되어 있지 않습니다.
플레이어별 비밀 토큰은 서버에 해시로만 저장합니다.
로컬 게임과 재접속 정보는 해당 브라우저에 저장됩니다. 브라우저 데이터를 지우면 복구할 수 없습니다.
서비스 워커는 온라인 API 응답이나 참가 토큰을 캐시하지 않습니다.

## 검증

```bash
pnpm test
pnpm typecheck
pnpm build
```

게임 규칙·새 능력·온라인 비공개 처리 검사를 포함합니다.
`pnpm test`, `pnpm typecheck`, `pnpm build`로 검증합니다.
Cloudflare CLI의 로컬 DB 초기화는 작업 환경의 네트워크 제한으로 완료하지 못했습니다.
의존성은 기존 설치본을 사용했으며, 새 컴퓨터에서의 전체 재설치는 검증하지 않았습니다.
실제 휴대폰 조작, PWA 설치, 사용자 Cloudflare 계정 배포는 아직 검증하지 않았습니다.
WebMCP 현재 판 조회 도구는 지원 브라우저가 있는 경우에만 등록됩니다.

## 문제 해결

- `no such table: chess_rooms`: 로컬은 `pnpm db:migrate:local`, 배포 DB는 `pnpm db:migrate:remote`를 실행합니다.
- 배포에서 DB를 찾지 못함: `wrangler.jsonc`의 임시 ID를 실제 D1 ID로 바꾸고 다시 빌드합니다.
- `node:sqlite` 또는 `.ts` 실행 오류: Node.js 24 이상인지 `node --version`으로 확인합니다.
- pnpm 버전 오류: 위에 적은 버전을 설치하고, `pnpm-lock.yaml`을 유지한 채 다시 설치합니다.
- 압축을 풀고 HTML 파일을 직접 열어도 실행되지 않음: 위 개발 서버 또는 Workers 배포가 필요합니다.


## 연습 모드 (실험판)

실제 로컬/온라인 대국과 분리된 AI 대국 및 자유 분석 화면입니다. 연습 탭에서 시작합니다.

- 실전평가: 자기 능력과 공개된 판·행동만 분석기로 전달합니다. 상대 능력은 허용된 풀의 후보를 규칙으로 재현해 추정합니다. 상대 실제 능력·탄약·숨은 기물 상태·되감기 스냅샷을 입력하지 않습니다.
- 이론평가: 양쪽 능력을 알고 분석합니다. 어느 모드에서도 상대의 미공개 가위바위보 선택은 읽지 않습니다.
- 사람 시점의 평가기와 상대 AI는 별도 입력으로 계산합니다. 실전평가는 사람의 관점으로 고정됩니다.
- 이동, 능력 사용, 승격, 추가 이동, 왕룩 선택 및 가위바위보를 공통 규칙 엔진으로 검증합니다.
- 쉬움/보통/어려움은 탐색 깊이와 계산 예산을 조절합니다. 웹 워커에서 계산하고 무르기·재시작·화면 이탈 시 이전 계산을 취소합니다.
- AI는 능력 발동 후보를 별도로 남겨 비교하며, 턴을 소모하지 않는 발동·연속 이동은 후속 이동까지 탐색합니다. 이동 방식 변화도 평가에 반영합니다.
- 평가 바, 백 기준 평가 점수, 백 승/무승부/흑 승의 예상치, 추천 행동과 분석선을 제공합니다. AI 대국에서 실시간 평가를 끌 수 있습니다.
- 왼쪽 막대는 백·무승부·흑 비율을 따로 표시하고 판 방향에 맞춰 뒤집힙니다. 계산 중에는 임의의 50% 대신 대기 상태를 표시합니다.
- 이전 장면 이동, 무르기, 다른 수로 분기, AI 일시정지, 자유 분석 전환, 같은 설정 새 대국, 브라우저 내 연습 저장/이어하기를 지원합니다.
- 히든 조건은 AI의 규칙 판정에만 반영합니다. 연습 화면은 도감용 설명과 중립적인 행동 이름을 사용하며 상세 종료 사유·특수승리 조건을 표시하지 않습니다.

### 평가의 한계

현재 AI는 제한된 후보 탐색과 기물·위치·능력 상태의 휴리스틱 평가를 사용하는 초기 실험판입니다. 난이도는 공인 등급이 아니며 모든 최선 수를 보장하지 않습니다. 승률은 자체 대국 데이터로 보정된 확률이 아니라 평가 점수를 변환한 예상치로, UI에 통계 보정 전임을 표시합니다. 후보가 많으면 일부 표본을 분석하며, 공개 정보로 상태 재구성이 되지 않거나 계산 시간이 초과되면 평가 불가로 표시하고 AI를 일시정지합니다. 분석선은 증명된 강제 승리 수순이 아닙니다.

연습은 브라우저 내에서 실행되므로 히든 조건을 화면에 노출하지 않는 UX이며, 개발자 도구로 규칙 코드까지 볼 수 없게 만드는 보안 장치는 아닙니다. 온라인 비공개 응답의 서버 처리는 변경하지 않습니다.
