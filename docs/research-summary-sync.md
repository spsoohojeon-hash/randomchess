# 무료 한도 절약: 로컬 원본 + 클라우드 요약

이제 실행기는 매 행동의 원본을 D1에 올리지 않습니다. 상세 기보, 체크포인트, GPU 학습 데이터와 모델은 기존 노트북의 `%USERPROFILE%\.randomchess-research`에 보관합니다.

약 60초마다 누적 판수·시작 능력별 승률·상성·최근 30판의 보드·학습 상태만 D1의 단일 스냅샷 행에 덮어씁니다. 정상적인 실행기 1개 기준 하루 약 1,440번의 요약 갱신입니다. 인증·설정·시간별 모니터·온라인 게임의 쓰기는 별도이므로 계정 전체 무료 한도를 보장하는 수치는 아닙니다.

## 적용 순서 (Windows)

수집기 창에서 Ctrl+C를 누르고 종료를 기다립니다. 자동 실행을 등록했다면 해당 작업도 중지합니다. 기존 데이터 폴더를 삭제하지 않습니다.

프로젝트 폴더에서 한 줄씩 실행합니다.

```powershell
cd C:\Users\minja\randomchess-ai
git pull --ff-only
pnpm.cmd research:setup
```

사이트 배포 성공 후, 시간별 모니터를 사용하고 있다면 함께 업데이트합니다.

```powershell
pnpm.cmd exec wrangler deploy --config wrangler.monitor.jsonc
```

그다음 수집기를 시작합니다.

```powershell
pnpm.cmd research:run
```

사이트 업데이트를 생략하면 새 `/runner/snapshot` API가 없어 동기화되지 않습니다. 기존 주소·비밀번호는 Enter로 유지합니다. 기존 자동 실행 작업을 사용하는 경우에는 수동 실행 대신 그 작업을 시작하세요.

## 동작과 확인

- 연구실 화면의 보드는 약 1분마다 최신 요약을 받습니다. 화면 자체 조회 간격은 5초이며 대국 계산 간격과 무관합니다.
- 시작/일시정지/학습 요청은 다음 요약 교환 때 적용되어 약 1분 지연될 수 있습니다. 즉시 중단하려면 PC에서 Ctrl+C를 사용합니다.
- 실행 후 최초 서버 응답으로 수집 허용을 확인해야 대국을 시작합니다. 이후 네트워크가 끊기면 마지막 허용 상태로 로컬 대국을 계속합니다. 원격 중지는 연결 복구 전까지 적용되지 않습니다.
- 요약 전송은 계산과 별도로 진행하므로 전송을 기다리며 다음 수를 멈추지 않습니다. 재연결하면 밀린 기보를 업로드하지 않고 최신 요약만 전송합니다.
- 600행동 제한 무승부, 4판 병렬, 상대 능력 비공개, 기존 CPU/GPU 학습은 유지합니다.
- 요약 모드의 판수는 현재 PC 로컬 DB 전체 기준입니다. 기존 D1 기록과 더하지 않아 같은 대국을 중복 집계하지 않습니다. 다른 PC에만 있는 데이터는 합산하지 않습니다.
- D1의 기존 상세 기록은 삭제하지 않습니다. 이전에 사용한 일일 한도는 이 변경으로 되돌아가지 않으며 기존 저장 용량도 줄지 않습니다.
- 상세 기보 다운로드는 새 요약 화면에서 제공하지 않습니다. 원본은 노트북 SQLite에 있으며 기존 `scripts/research/export.mjs`로 완료 대국의 학습 표본을 내보낼 수 있습니다.
- 클라우드는 원본 백업이 아닙니다. 수집기·학습기를 종료한 뒤 개인 데이터 폴더를 따로 백업하세요.

첫 1분 뒤 연구실에 'PC 요약 약 1분마다 동기화'가 표시되고 판수가 갱신되는지 확인합니다. 실제 D1 사용량은 Cloudflare 사용량 화면에서 비교합니다.
