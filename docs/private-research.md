# 개인 AI 연구실

주소: `/research`. 게임 화면에는 링크를 추가하지 않습니다. 주소가 알려져도 비밀번호가 없으면 모든 기록/통계/내보내기 API가 거부됩니다. 비밀번호 8자 이상과 수집기 토큰 32자 이상이 Cloudflare Secrets에 둘 다 있어야 열립니다. 초기 상태는 수집 중지입니다.

## 최초 설정

Node 24+, pnpm, 이 저장소가 있는 **항상 켜진 컴퓨터 또는 Linux 서버**에서:

```sh
pnpm install --frozen-lockfile
pnpm exec wrangler login
pnpm research:setup
```

setup은 최신 코드를 빌드하고 선택한 Worker(기본 `randomchess`)에 배포한 다음, 비밀번호와 별도 수집기 토큰을 무작위 생성해 Cloudflare의 `RESEARCH_PASSWORD`, `RESEARCH_RUNNER_TOKEN` 비밀값으로 등록합니다. GitHub 자동 배포가 연결되지 않아도 이 명령으로 배포할 수 있습니다. 값은 커밋하지 않습니다. 사용자 홈의 `.randomchess-research/config.json`만 소유자 전용 권한으로 보관합니다. 비밀번호는 터미널에 출력하지 않고 비공개 설정 파일에 보관합니다. 직접 고른 비밀번호를 사용하려면 저장소 밖의 소유자 전용 파일에 넣고 `RESEARCH_PASSWORD_FILE=/private/path/password.txt pnpm research:setup`으로 실행하세요. 파일 마지막의 줄바꿈 하나만 제거하며 나머지 문자는 그대로 사용합니다. 이 옵션은 재실행 때 비밀번호를 변경하는 데도 사용할 수 있습니다. 설정이 실패하면 Cloudflare 로그인 후 재실행합니다. 기존 설정을 재사용하므로 실패할 때마다 비밀번호가 바뀌지 않습니다. 기존 체크아웃에서는 먼저 `git pull --ff-only`로 최신 코드를 가져오세요.

```sh
pnpm research:run
```

연구실에 로그인하고 **수집 시작**을 누릅니다. 홈페이지/연구실을 닫아도 이 실행기가 켜져 있으면 수집합니다. **일시정지**는 진행 중인 계산을 마친 뒤 최대 약 20초 안에 적용됩니다. 재개하면 저장한 대국을 이어갑니다.

Linux 상시 서비스는 setup이 만든 사용자 서비스를 활성화합니다:

```sh
systemctl --user daemon-reload
systemctl --user enable --now randomchess-research
```

서버 관리자는 해당 사용자의 `loginctl enable-linger USERNAME`을 설정해야 로그아웃 후에도 서비스가 유지됩니다. 서비스는 실패하면 재시작합니다. 실행기를 둘 이상 같은 데이터 경로에 실행하지 마세요. 별도 서버에서는 고유한 홈 경로를 사용합니다. 하나의 호스트에서 기본 두 대국을 번갈아 진행합니다. 개인 config의 `lanes`를 1~8로 바꿀 수 있습니다. 현재 구현은 순차 계산이며 lanes는 CPU 병렬 작업 수가 아닙니다.

Codespaces, 잠자는 노트북, ChatGPT 임시 실행환경은 24시간 서버가 아닙니다. 이 저장소에는 공개 GitHub Actions 대국 작업을 만들지 않습니다. 상시 실행기/서버 비용과 데이터 저장 비용은 별도이며 OpenAI API를 호출하지 않습니다. Cloudflare 무료 Worker에서 어려움 AI의 무거운 탐색을 실행하지 않습니다.

## 대국과 데이터

- 현재 전체 능력 풀에서 중복 없이 백/흑을 무작위로 뽑고 어려움으로 고정합니다.
- 양쪽 AI 입력은 `publicGame`으로 가린 자기 관측, 공개된 행동 가능 목록, 별도로 가린 최근 되돌리기 상태뿐입니다. 실제 숨은 카드/덱/가위바위보 선택은 넣지 않습니다.
- 미공개 카드와 미래 덱을 독립적으로 샘플링해 어려움 탐색을 합니다. 이 추정은 근사값입니다. 공개된 복합 행마/버로우 등의 세부 상태를 완전히 복원하는 신경망이 아닙니다. 기록에 `beliefApproximate: true`와 `analysis.incomplete`를 남깁니다.
- **행동 수/반복 수 상한은 없습니다.** 끝나지 않는 대국은 계속 진행될 수 있습니다. 진행 상태를 무승부로 바꾸거나 학습용 승패를 만들어내지 않습니다.
- 데이터베이스/API 오류는 수집을 멈추고 재시도합니다. 불법 AI 행동이나 판단 불가는 `blocked`로 분리합니다. 무작위 수를 대신 두지 않습니다. 이러한 대국은 승률/승패 학습에서 제외됩니다.
- 규칙/정책 소스 해시가 바뀌면 진행 중이던 이전 버전 대국을 `blocked`로 보관하고 새 대국을 시작합니다. 서로 다른 버전의 라벨을 한 판 안에 섞지 않습니다.
- 행동별 압축 기보와 체크포인트를 로컬 SQLite에 원자적으로 저장한 후 인증 API로 D1에 전송합니다. 응답 유실 후 같은 기록을 다시 보내도 중복되지 않습니다. 로컬 기록은 삭제하지 않습니다.
- 저장 용량은 무한하지 않습니다. D1/디스크 한도를 만나면 멈추며, 새 서버/더 큰 저장 공간으로 이전해야 합니다. 공간 확보를 위해 기보를 자동 삭제하지 않습니다. 대규모 학습 전에 용량을 계획하세요.

## 딥러닝용 내보내기

최근 대국은 연구실에서 JSONL로 받을 수 있습니다. 이것은 심판의 실제 상태도 들어 있는 **비공개 원본**입니다. 외부 공개/학습 입력으로 그대로 사용하지 마세요.

실행기에서 완료된 모든 대국을 학습용으로 스트리밍 변환:

```sh
pnpm research:export
```

기본 출력은 비공개 홈의 `training.jsonl`입니다. 기존 파일을 덮어쓰지 않습니다. 다른 파일을 지정하려면:

```sh
node scripts/research/export.mjs /private/path/training-v2.jsonl
```

학습 행의 `features`에는 해당 플레이어의 가려진 관측만 들어갑니다. 행동은 정책 타깃, 최종 승패는 플레이어 기준 `value`(-1/0/1)입니다. 추정 평가점수를 최종 승패로 대신 쓰지 않습니다. 대국 ID 기준으로 train/validation/test를 80/10/10 분리해 같은 대국의 수들이 서로 다른 분할에 섞이지 않게 합니다. 끝나지 않은/오류 대국은 제외합니다. 검색 점수는 보정된 실제 승률이 아닙니다.

## 신경망 학습

연구실에서 **자동 학습**을 켜 두면 기본 100판을 추가 완료할 때마다 실행기가 별도 Node 프로세스로 학습합니다. **지금 학습 요청**으로 수동 요청할 수도 있습니다. 학습은 OpenAI API나 외부 모델 API를 호출하지 않습니다. 계산량과 메모리를 실행 서버에서 사용합니다.

학습 입력은 각 플레이어의 가려진 관측뿐입니다. 64→32 은닉층의 MLP가 합법 수 중 수 선택 정책과 플레이어 기준 최종 승패(-1/0/1)를 함께 학습합니다. 역전파와 Adam을 사용합니다. 기본 5 epoch, 최대 12,000개의 샘플을 대국별로 고정 분할한 train/validation/test에서 각각 reservoir sampling으로 뽑습니다. 테스트 분할은 모델 선택·승격에 사용하지 않습니다. 수 제한 없는 전체 원본은 계속 보관하고 학습 한 번의 메모리 사용량만 제한합니다.

학습을 시작하려면 샘플에 학습 대국 20개, 검증 대국 5개, 테스트 대국 5개와 학습 행동 256개 이상이 있어야 합니다. 초기 즉시 종료 대국·미완료·오류 대국만으로 신경망을 학습하지 않습니다. 현재 규칙/정책/입력 인코더 해시와 일치하는 기록만 사용합니다.

검증 손실이 균등 정책+학습 세트 평균 승패 기준보다 1% 이상 낮고, 승패 예측 오차가 악화되지 않는 허용범위 안에 있으며, 기존 모델이 있으면 기존 모델보다 검증 손실이 0.5% 이상 개선되어야 적용합니다. 최종 테스트 점수는 모델 선택 이후에만 기록합니다. 이 검증은 실제 상대와의 승률/Elo 검증이 아니며, 강해졌다고 단정할 수 없습니다.

승격된 정책은 **개인 수집기의 어려움 탐색**에서 수 후보에 작은 우선순위(평가값 최대 ±0.4)를 더합니다. 기존 어려움 탐색·합법 수 검사를 유지합니다. 승패 예측 헤드는 보조 학습 목표이며, 원래 평가 함수를 대체하지 않습니다. 공개 게임/연습 모드에 모델이나 연구 결과를 전송하지 않습니다.

모델은 개인 홈의 `models/`와 `active-model.json`에 원자적으로 저장합니다. 중단 시 완료한 epoch의 가중치와 Adam 상태를 `training-checkpoint.json`에서 복구합니다. 같은 학습 샘플/설정이면 이어서 학습하고, 샘플이 바뀌면 검증된 기존 모델부터 새 학습을 시작합니다. 실패하거나 기준을 통과하지 못해도 기존 모델은 유지됩니다. 규칙이 바뀌면 호환되지 않는 모델은 적용하지 않습니다.

실행기 없이 수동 학습만 하려면:

```sh
pnpm research:train
```

연구실 상태 화면은 연결된 수집기의 보고를 통해 갱신됩니다. 수집기가 꺼진 상태의 수동 학습 결과는 로컬 `training-status.json`에 저장되며, 수집기를 다시 켜면 표시됩니다. 자동 학습을 끄면 다음 작업을 시작하지 않고 이미 시작한 작업은 끝까지 진행합니다. 수집 일시정지와 학습 설정은 별개입니다.

## 보안과 운영

- HTTPS, HttpOnly/Secure/SameSite=Strict 12시간 쿠키, 서버 서명 검증, 로그인 시도 제한, 출처 검사, no-store를 사용합니다.
- 수집기 토큰은 업로드/제어 상태 조회만 허용하며 관리자 통계/다운로드 권한은 없습니다. 비밀번호 변경은 세션을 무효화합니다.
- 일반 방문자와 로그인 전 브라우저 HTML에는 기보/통계가 포함되지 않습니다. 서비스 워커는 연구실/API를 캐시하지 않습니다.
- 비밀번호 공유 시 그 사람도 접근할 수 있습니다. 공개 PC에서는 **잠그기**를 누르세요. Cloudflare/GitHub 계정도 소유자 외 접근 권한을 주지 마세요.
- 로컬 SQLite와 config는 소유자 전용 파일입니다. 별도 관리자/호스팅 사업자로부터의 종단간 암호화를 제공하는 구조는 아닙니다.
- 데이터/보고서/토큰을 GitHub나 공개 Actions 로그에 올리지 마세요. 실행기는 공개 로그에 기보/카드/승패/비밀값을 출력하지 않습니다.

서버를 옮길 때 서비스를 중지한 뒤 개인 홈 디렉터리 전체(SQLite WAL/SHM 포함)를 안전하게 옮깁니다. 코드만 업데이트하려면 작업을 중지하고 git pull, pnpm install 후 서비스를 다시 시작합니다.
